# 科研结果判读

## 动作架构与结构依赖

本模块负责证据比较与判断；写入前读取[文档](../../structures/documents/GUIDE.md)、[结果](../../structures/results/GUIDE.md)，再读项目对应职责区的实际说明。

流程：研究问题与可比证据 → 核对定义／人群／检查 → 形成观察和解释 → 决定下一动作。

输出与边界：FINDINGS、必要决定与 TASK；新计算表图由新 run 保存，不写进 references。

具体输入、操作、输出和验收样例见 [EXAMPLE](EXAMPLE.md)。目录及接口约束由结构层维护，下文只规定动作。

先定位具体运行、方案行和预测／指标文件，核对检查状态。按目标、人群、划分、指标定义和选择用途组织比较；QC 改变人群或融合取交集时不能直接归因于方法改进。

分类关注标签、基线、不平衡与验证；回归区分相关性、误差与校准；聚类区分内部指标、稳定性和外部检验。外部标签用于选簇后不再称为独立验证。失败不是负结果，未检查不是通过，最高分不自动成为采用结论。

记录观察→解释及限制→对安排的影响→重新考虑条件，并引用证据。保留探索与确认的区别，方案修改不能追写成预先设定。自动更新指标与状态，人工决定及其授权依据保留历史；缺少依据时给出待核对项，不编造结论。

按 [日常操作规范](../../docs/daily-operations.md) 使用六行判断条或等价分析模板，维护待解释积压与重试条件。报告全变量、全条件、剔除前后双报、协变量调整前后双报，不适用明确说明。关键论文数字安排独立复算，保留可执行计算与差异处置；新的独立检查者不以已有结论为答案。不得仅凭 LLM 复述宣布复核通过。

## 完整工作流

按本模块动作读取 [results-workflow](../../docs/results-workflow.md)。这些文档包含模板、证据位置、输入输出、恢复与验收要求，不能只执行本页摘要便宣称流程完成。

按 [研究原则](../../docs/research-principles.md) 核对当前阶段、接手需求和适用证据声明；已有信息引用原处，不重复填表。
