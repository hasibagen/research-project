# 判读动作样例

合成请求：比较 demo-rest 两个阈值方案。假定两份结果已存在，但尚未确认可比性。

输入：两个完整运行身份、通道 QC 表、有效配置、纳入清单和 CHECKS。
动作：先核对输入人群、通道集合和指标定义 → 若阈值同时改变了纳入集合，分别报告各集合结果及共同集合比较 → 把事实、解释、限制写 FINDINGS → 需要新汇总表时交 run 动作建立汇总 run。

输出：有证据范围的比较和后续任务，不直接宣布某阈值更好；未达到预设验收时保留待判断状态。

验收：每个数字指向实际产物；人工解释没有改写原始指标；自己产生的分析没有塞进 references。说明结构见 [文档样例](../../structures/documents/EXAMPLE.md)。
