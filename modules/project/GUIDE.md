# 科研项目与项目群管理

## 动作架构与结构依赖

本模块负责项目范围与日常接续；写入前读取[整体项目](../../structures/project/GUIDE.md)、[文档](../../structures/documents/GUIDE.md)，再读项目对应职责区的实际说明。

流程：入口与当前目标 → 核对权威路径／共享依赖 → 协调对应动作 → 保存证据与接续。

输出与边界：PROJECT 中的资源和入口、相关 TASK 的接续；不代替 organize 重排目录。

具体输入、操作、输出和验收样例见 [EXAMPLE](EXAMPLE.md)。目录及接口约束由结构层维护，下文只规定动作。

本 skill 负责整个项目的组织与生命周期，不限于实验记录。接入、继续或收尾具体项目时必须读取 [具体项目结构规范](../../structures/documents/GUIDE.md)，核对 PROJECT 中的权威路径，按固定触发维护计划、日志、进度、结果模板与判断；按项目实际约定核对检查触发条件。涉及大小项目关系、目录与代码架构、共享材料、跨仓或多机组织时，先读 [项目架构规范](../../structures/project/scope.md)，用 [项目地图模板](../../assets/templates/project-map.md) 记录现状、目标与接入步骤。区分项目群、独立项目、仓内主线和一次运行；小项目跳过不需要的层级。先映射后迁移，不为统一外观移动旧材料。

读取项目入口和用户指定 plan，保留现有目录与多主线结构。先确认本次目标、授权范围、证据来源和完成标准；历史结论未核对时标明来源缺口。普通代码或文档任务不必建立分析运行。

研究任务采用“通用骨架＋分类／回归／聚类字段＋问题实例”。先读 [分析模板](../../assets/templates/analysis.md)，按分析类型选择字段，不适用写理由，不删除必填的身份、验证、证据与状态；一个问题可以关联多个方案和运行。多主线引用共享材料，不重复复制。不要把实验范式、预测目标和管理待办都命名为 task。

方向／计划／任务依赖、排序、暂停恢复、当前焦点和进度审计交给 [plan](../plan/GUIDE.md)。总入口只定位项目和安排专项，不重复维护第二套计划协议。

按当前动作读取同一大 skill 的 modules/{code,run,interpret,release}/GUIDE.md，分别处理实现、执行、判断和交付；从根 SKILL.md 路由，不调用旧独立 skill。

接手或交接时核对当前目标、已完成证据、运行状态、阻塞与下一步。发现并发改动先合并，不以旧稿覆盖。更新问题页的自动区，保留人工说明和判断历史。

先读 [日常操作规范](../../docs/daily-operations.md)，按第 0 步用现有 Markdown／LOG 开始，不等待平台。开工保存可恢复状态并做开局三件事；首屏保留八字段，尤其待解释积压、墙钟余量和核对边界；收尾四问逐项给出实际状态。六行判断条是默认最小格式，可由现有分析模板承载。

日常规范与长篇产品设计分开。安全四口、两份备份和终评准入是本地明确约定，不能在“通用化”时删掉。同一文档一次只由一个工具写，写前重读，落盘前核对基线。

需要查询设计、深读材料、工具选型或机制出处时，先读 [文档索引](../../docs/README.md)，再只读相关章节；历史稿不覆盖当前日常规范。

一个项目允许多个并行 plan；方向与 plan 不强制一一对应。按 [具体项目结构规范](../../structures/documents/GUIDE.md) 使用 PROJECT.md 内计划入口定位计划，按计划维护任务、日志、结果与判断，项目层只汇总。共享运行保留单一事实来源，禁止用一个“当前主线”覆盖其他计划。

## 完整工作流

按本模块动作读取 [system-architecture](../../docs/system-architecture.md)。这些文档包含模板、证据位置、输入输出、恢复与验收要求，不能只执行本页摘要便宣称流程完成。

按 [研究原则](../../docs/research-principles.md) 核对当前阶段、接手需求和适用证据声明；已有信息引用原处，不重复填表。

创建与结构整理转入 [organize](../organize/GUIDE.md)；先读 [文件归属规则](../../structures/project/placement-rules.md)，使用 [整理方案模板](../../assets/templates/structure-adoption-plan.md)。不能仅凭目录清单生成计划或把历史材料按名字批量归档。
