# 项目接续样例

合成项目 demo-rest，入口 /srv/research/demo-rest/codebase/docs/PROJECT.md；状态仅为教学假设。

输入：用户要求继续 rest-qc 计划。读取 PROJECT 的权威位置、/srv/research/demo-rest/codebase/docs/plans/rest-qc/TASK.md 和 LOG 最近事件，发现上次留下“产物待检查”。

动作：按结果 README 定位 run_20261021_143000_qc，核对实际作业和文件，再交 run 动作检查、interpret 动作解释。目录位置不变，无需启动整理或另建项目 LOG。

输出：实际检查证据进入 run，任务状态按证据更新，LOG 追加接续事件；PROJECT 只有资源或当前重点变化时才改。

验收：下次只读项目入口即可定位任务、证据与下一步；未访问远端作业时写“作业状态未核对”，不能据旧日志判断已完成。结构样例见 [完整项目](../../structures/project/EXAMPLE.md)。
