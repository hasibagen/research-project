# 计划动作样例

合成项目 demo-rest 的 rest-qc 计划中，用户提出比较两个通道阈值。

输入：当前 PLAN、TASK、既有负结果，以及阈值比较目标。

先核对 PLAN 的“本计划资源与目录”：本次使用哪个数据批次、哪个代码入口和配置、结果根及旧基准在哪里、阈值依据来自哪份材料。缺失的路径先核对或标未知；不能以“项目文档里有”省略。填写例见 [计划资源表](../../structures/documents/EXAMPLE.md#本计划资源与目录示例)。
动作：判断它仍属同一质控问题 → 在 PLAN 记录方案修订与比较条件 → TASK 增加 compare-thresholds，明确前置检查、验收和下一步 → LOG 记变化。两个实际计算由 run 动作建立独立 run，不新建两个 plan。

输出：研究方案和任务身份；在计算发生前 evidence 留空，不能先标完成。比较结果到来后引用具体 run 产物。

验收：计划依赖和任务身份可校验，状态只有 TASK 一份；更换阈值没有复制计划、结果或文档体系。完整文档示例见 [文档结构](../../structures/documents/EXAMPLE.md)。
