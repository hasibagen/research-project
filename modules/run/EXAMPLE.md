# 运行与恢复样例

合成请求：执行 demo-rest 的质控方案。所有身份为示例，未提交真实作业。

输入：固定 batch-01、真实有效配置、代码身份和环境；结果根 /srv/research/demo-rest/storage/results。
动作：核对准入和资源 → 建立独立 run_20261021_143000_qc → 保存来源和配置 → 执行实际入口 → 保存退出信息、表图和检查 → 构造并验证真实 record → 显式登记台账 → 回填 TASK／LOG。

失败分支：进程中断但输入、配置与代码没变，先核实旧作业是否仍在运行；程序支持恢复才沿用原 run，新日志不覆盖旧日志。若代码修复改变结果，则新建 run。

输出：可追溯产物和已检查范围。没有产物的指标留缺失，不填零；未显式导入不说台账已同步。目录与记录关系见 [结果样例](../../structures/results/EXAMPLE.md)。
