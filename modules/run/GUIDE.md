# 科研运行与恢复

## 动作架构与结构依赖

本模块负责执行与恢复；写入前读取[代码与配置](../../structures/code/GUIDE.md)、[数据](../../structures/data/GUIDE.md)、[结果](../../structures/results/GUIDE.md)，再读项目对应职责区的实际说明。

流程：固定输入／代码／有效配置 → 准入与作业核对 → 执行或恢复 → 检查产物／显式导入 → 回填任务。

输出与边界：run 来源与产物、检查和任务接续；不把运行成功等同科学采用。

具体输入、操作、输出和验收样例见 [EXAMPLE](EXAMPLE.md)。目录及接口约束由结构层维护，下文只规定动作。

创建或定位 run 前读取 [结果目录架构](../../structures/results/GUIDE.md)，核对 PROJECT 中的实际结果根与旧布局映射。

先读项目入口、方案、执行脚本与下方共同契约。展开有效配置，固定输入身份、代码快照、环境、模板版本与方案修订。新执行使用独立输出目录；恢复前核对原执行状态，不盲目重提未知远端作业。

多步骤任务优先复用已接入 Snakemake；单步入口仍可直接运行。只展开已授权方案，不默认做全笛卡尔积。机器资源、执行器与路径映射独立于科学参数；每台机器实际 IO 解析为绝对路径。

按依赖确定复用和重算边界；文件存在不等于产物有效。完成后核对退出码、预期产物、内容身份与科学检查。失败保留日志，缺失不填零。运行来源持续记录；运行包导出与结果导入使用公共程序，失败不抹去实际执行。

多机结果先进入暂存区，核对后合并；相同身份不同内容保留冲突。已完成、已回传、已验收和已备份分别报告。真实超算执行器未经测试不得宣称支持。

执行前必读 [日常操作规范](../../docs/daily-operations.md) 的安全、备份和终评准入。naming/ 姓名映射永不上超算、永不入仓；被试 ID 永不重用；AI 口先脱敏。核对原始材料第二介质与备份校验记录，不能把回传当备份。

终评不进入默认目标、扫描或自动重试。核对留出集准入条件、方案冻结、验证用途与已有确认依据；不因目标可执行就运行。缺少准入只暂停终评。运行回执记录墙钟余量和核对时间，结果回来先标待解释；复用前检查依赖身份及产物过期情况。

## 完整工作流

按本模块动作读取 [snakemake-workflow](../../docs/snakemake-workflow.md)；按本模块动作读取 [results-workflow](../../docs/results-workflow.md)。这些文档包含模板、证据位置、输入输出、恢复与验收要求，不能只执行本页摘要便宣称流程完成。

按 [研究原则](../../docs/research-principles.md) 核对当前阶段、接手需求和适用证据声明；已有信息引用原处，不重复填表。

临时计算写当前 run 的 tmp/；不得自动创建仓根或数据盘根 scratch／tmp／temp。使用外部集群临时存储时按 [归属规则](../../structures/project/placement-rules.md) 登记并隔离，恢复前保留依赖文件。
