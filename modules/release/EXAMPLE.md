# 交付动作样例

合成请求：为 demo-rest 准备一个本地教学包，未授权上传。

输入：明确选中的 QC 图表、来源 run、代码和数据身份、检查及许可信息。
动作：核对采用条件 → 在 rest-qc/DELIVERY 固定来源与用途 → 用真实文件生成独立包 → 检查清单、校验和与来源链接 → 记录实际检查范围并交付本地位置。

输出：采用记录和可追溯包；如果复算尚未执行就明确注明。准备成功不等于已发布，元数据检查不等于科学验收。

验收：从每个文件能回到来源，未混入其他版本或身份映射；包内 README 有内部树与使用样例。具体结构见 [交付样例](../../structures/delivery/EXAMPLE.md)。
