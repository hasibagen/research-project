## 开始使用

conda 环境、安装、运行、验证与恢复命令：核对真实入口后填写，不能把占位说明当命令。
数据与结果位置以 PROJECT 的实际绝对路径为准，run 不绑定计划。

使用样例：从 PROJECT 找到计划，读 PLAN 与 TASK，按验收标准执行；产生结果时保存独立 run 和来源，再回填任务及解释。首次生成仅有文档骨架，尚无科学代码、数据或运行。

代码、数据、结果等职责区实际建立时，各自填写内部架构和具体使用样例，并把真实入口加入本页；小模块可合写章节。整体树以 AGENTS 为准，细节以各区说明为准。

## 版本与维护

修改目录或权威路径时，同步 AGENTS 中的当前架构和相关入口。大于 5 MB 的文件不入 jj／Git，检查办法见 AGENTS。首次生成不自动初始化仓库或安装 hook。

若启用 results-templates，那只是运行教学样板；其中无效哈希不能导入真实台账。
